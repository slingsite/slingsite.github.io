WebP-Vorschaubild aus MP4 extrahieren

Erhalten Sie den ersten Frame Ihrer MP4-Videos als WebP, leicht und bereit fürs Web.

Videos hier ablegen

MP4, WebM, MOV und MKV, so viele Sie möchten. Ihr Computer erledigt die Arbeit, daher dauern lange Videos eine Weile.

MP4 ist das verbreitetste Videoformat und wird von Smartphones, Kameras, Bildschirmrekordern und Videoplattformen verwendet. WebP ist das moderne Bildformat des Webs, bei ähnlicher Qualität deutlich leichter als JPG. Dieses Tool nimmt den ersten Frame jedes MP4-Videos und speichert ihn als WebP, ohne etwas hochzuladen.

So extrahieren Sie ein WebP-Vorschaubild aus MP4

  1. Ziehen Sie Ihre MP4-Videos in das Feld oben oder klicken Sie, um sie auszuwählen. Sie können beliebig viele hinzufügen.
  2. WebP ist bereits als Ausgabeformat ausgewählt. Aktivieren Sie weitere Formate, wenn Sie diese ebenfalls brauchen.
  3. Optional: Öffnen Sie die Erweiterten Einstellungen, um das Vorschaubild nach Prozent, Breite oder Höhe zu skalieren und weitere Größen hinzuzufügen.
  4. Klicken Sie auf Vorschaubilder extrahieren und laden Sie jedes Bild einzeln oder alle auf einmal herunter. Nichts wird hochgeladen: Alles läuft in Ihrem Browser.

Warum MP4-Vorschaubilder als WebP speichern?

Das Vorschaubild ist das Erste, was man vor dem Abspielen sieht. Wenn Sie es direkt aus dem MP4 entnehmen, erhalten Sie ein Bild in genau der Auflösung und den Farben des Videos, bereit als Poster auf Ihrer Website, als Cover in einer Galerie oder als Vorschau in einem Dokument. Für ein Posterbild auf einer Website liefert WebP ein scharfes Vorschaubild, das schnell lädt, und jeder moderne Browser zeigt es an.

Häufig gestellte Fragen

Welche MP4-Videos werden unterstützt?

MP4-Dateien mit H.264-Video funktionieren in jedem modernen Browser. MP4-Dateien mit HEVC (H.265) oder AV1 funktionieren, wenn Ihr Browser und Ihr Gerät sie dekodieren können.

Kann ich ein WebP-Vorschaubild als Video-Poster verwenden?

Ja. Das poster-Attribut des HTML-Elements video akzeptiert jedes Bild, das der Browser anzeigen kann, und alle modernen Browser zeigen WebP an.

Werden meine Videos hochgeladen?

Nein. Der erste Frame wird in Ihrem Browser auf Ihrem Gerät dekodiert und als Bild gespeichert. Ihre Videos werden nie an einen Server gesendet, daher eignet sich das Tool auch für private Dateien.
