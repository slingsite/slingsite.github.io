Ändern Sie die Größe Ihrer Videos

Ein 4K-Video hat viermal so viele Pixel wie ein 1080p-Video und ist viel schwerer zu speichern, zu versenden und zu streamen. Die Auflösung zu senken ist die wirksamste Methode, ein Video zu verkleinern, wenn die Zuschauer nicht so viele Details brauchen. Ziehen Sie Ihre Videos hinein, wählen Sie die neue Größe und laden Sie sie herunter, mit Ton.

So ändern Sie die Größe von Videos

  1. Ziehen Sie Ihre Videos in das Feld oben oder klicken Sie, um sie auszuwählen. Sie können beliebig viele hinzufügen.
  2. Wählen Sie die neue Größe: einen Prozentsatz des Originals (standardmäßig 50 %), eine genaue Breite oder eine genaue Höhe. Klicken Sie auf Weitere Größen, um mehrere Versionen auf einmal zu erhalten.
  3. Optional: Öffnen Sie die Erweiterten Einstellungen, um das Ausgabeformat zu ändern oder den Ton zu entfernen. Standardmäßig bleibt MP4 MP4 (H.264), WebM bleibt WebM, und MOV oder MKV werden zu MP4.
  4. Klicken Sie auf Größenänderung starten und laden Sie jede Datei einzeln oder alle auf einmal herunter. Nichts wird hochgeladen: Alles läuft in Ihrem Browser.

Größe nach Prozent, Breite oder Höhe ändern

Mit einem Prozentsatz skalieren Sie einen ganzen Stapel: 50 % machen aus 4K 1080p und aus 1080p 540p. Mit einer genauen Höhe zielen Sie auf eine Standardauflösung wie 720 oder 1080 Pixel. Mit einer genauen Breite passen Sie das Video an ein Website-Layout an. Die andere Seite wird immer aus dem Seitenverhältnis berechnet, sodass das Video nie verzerrt wird.

Häufig gestellte Fragen

Bleibt der Ton erhalten?

Ja, standardmäßig. Kann der Browser den Ton einer Datei nicht lesen oder schreiben, erhalten Sie eine Meldung statt eines stummen Videos. Sie können den Ton in den Erweiterten Einstellungen auch abschalten, etwa für Hintergrundvideos.

Kann ich ein Video auf 4K hochskalieren?

Nein. Das Tool macht ein Video nie größer als das Original, weil Hochskalieren die Datei schwerer macht, ohne Details hinzuzufügen.

Werden meine Videos hochgeladen?

Nein. Das Video wird in Ihrem Browser auf Ihrem Gerät dekodiert und kodiert. Nichts wird an einen Server gesendet, daher gibt es auch keine Größenbegrenzung außer dem Speicher Ihres Geräts.
