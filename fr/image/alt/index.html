Générez l’alt text de vos images

Un brouillon en anglais pour chaque image, écrit sur votre appareil. Vos images ne sont jamais envoyées.

Déposez vos images ici

JPG, PNG, WebP, GIF et AVIF, autant que vous voulez. Votre ordinateur fait le travail : un gros lot prend donc un moment.

L’alt text (texte alternatif) décrit une image pour les personnes utilisant un lecteur d’écran et pour les moteurs de recherche. L’écrire pour toute une galerie prend du temps. Cet outil vous donne un point de départ : un modèle d’IA sur votre propre appareil écrit une courte description par image, et vous la relisez.

Le texte est toujours en anglais, quelle que soit la langue de cette page. Traduisez-le si votre site utilise une autre langue.

Comment générer un alt text

  1. Déposez vos images dans le cadre ci-dessus, ou cliquez pour les choisir.
  2. Cliquez sur le bouton et patientez. La première fois, votre navigateur télécharge le modèle (environ 216 Mo). Ensuite, il reste dans votre navigateur.
  3. Lisez chaque brouillon, modifiez-le et copiez-le.

C’est un brouillon

Le modèle décrit ce qu’il voit en termes généraux : "A bowl of bread rolls on a red and white cloth." Il ne sait rien de votre page, de votre marque ni de la raison d’être de l’image, et il peut se tromper. Un bon alt text (texte alternatif) dit ce que l’image signifie dans son contexte, relisez donc chaque brouillon avant de publier.

Questions fréquentes

Mes images sont-elles envoyées ?

Non. Le modèle s’exécute dans votre navigateur, sur votre appareil. Seul le modèle lui-même est téléchargé, depuis Hugging Face. Vos images ne sont envoyées nulle part.

Quelles langues sont prises en charge ?

Uniquement l’anglais pour le moment. Vous pouvez modifier le texte ou le traduire vous-même.

Puis-je l’obtenir en compressant ?

Oui. Dans le compresseur d’images, activez l’option d’alt text (texte alternatif) : il apparaît dans l’extrait HTML de chaque image.

Quel modèle est utilisé ?

Florence-2, sous licence MIT.
