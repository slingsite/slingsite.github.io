调整 PNG 图片大小

将 PNG 标志、图标和截图缩放到精确尺寸，透明效果完整保留。

将图片拖放到这里

JPG、PNG、WebP、GIF和AVIF，数量不限。处理工作由你的电脑完成，所以大批量文件需要一点时间。

PNG 是无损格式，因此尺寸大时文件会很重。把标志、图标、截图或抠图缩小到实际显示的尺寸，可以大幅减小文件体积，透明背景也会原样保留。拖入您的 PNG，选择尺寸，然后下载调整后的版本。

如何调整 PNG 图片大小

  1. 将您的 PNG 文件拖放到上方区域，或点击选择文件。数量不限。
  2. 选择新尺寸：原始尺寸的百分比（默认 50%）、精确宽度或精确高度。点击“更多尺寸”可一次获得多个版本。
  3. PNG 已被选为输出格式。如需体积小得多的 WebP 或 AVIF 副本，请打开“高级设置”。
  4. 点击“开始调整大小”，然后逐个或一次性下载所有文件。文件不会被上传：一切都在您的浏览器中完成。

为什么要调整 PNG 图片大小？

应用图标、网站图标、社交头像和文档截图都需要精确的尺寸。在浏览器中调整大小，几秒钟就能得到这些尺寸，缩放平滑、质量高，透明通道完好。在这里添加的其他格式图片也会保存为 PNG。

常见问题

会保留透明背景吗？

会。透明和半透明像素会保留在调整后的 PNG 中。

可以把小图标放大吗？

不可以。工具从不放大，因为放大小图只会让它变模糊。请从您手头最大的版本开始。

我的图片会被上传吗？

不会。所有处理都在您的浏览器中、在您的设备上进行。您的图片永远不会上传到服务器，因此私密或机密文件也可以放心使用。
