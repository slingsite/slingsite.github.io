将图片转换为 WebP

用 WebP 为您的 JPG、PNG 和 GIF 文件瘦身，所有现代浏览器都支持这种图片格式。

或拖放

支持: JPG, PNG, WEBP, GIF, AVIF

WebP 是网页图片的首选格式：在画质相近的情况下，它通常比 JPG 小 25% 到 35%，像 PNG 一样支持透明，并且所有主流浏览器都能显示。拖入您的图片，即可获得可直接用于网站、博客或网店的 WebP 版本。

如何将图片转换为 WebP

  1. 将您的图片拖放到上方区域，或点击选择文件。数量不限。
  2. WebP 已被选为输出格式。如需其他格式，也可以一并开启。
  3. 可选：打开“高级设置”，按百分比、宽度或高度调整尺寸，并添加更多尺寸。
  4. 点击“开始转换”，然后逐个或一次性下载所有文件。文件不会被上传：转换在您的浏览器中完成。

为什么要将图片转换为 WebP？

更小的图片意味着更快的页面、更好的 Core Web Vitals 指标，以及访客更少的流量消耗。WebP 保留透明通道，因此既能替代 JPG 照片，也能替代 PNG 图形。动态 GIF 会转换为第一帧的静态 WebP。

常见问题

所有浏览器都支持 WebP 吗？

是的。Chrome、Edge、Firefox、Safari（14 版起）及其移动版本都能显示 WebP，几乎覆盖如今的所有访客。

WebP 会保留透明吗？

会。PNG、GIF 或 AVIF 文件中的透明区域在 WebP 中依然透明。

我的图片会被上传吗？

不会。转换完全在您的浏览器中、在您的设备上进行。您的图片永远不会上传到服务器，因此私密或机密文件也可以放心使用。
